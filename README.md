## Run locally

Use this command below to clone the government hub locally.

```bash
git clone https://github.com/resilient-roleplay/gov-website.git

cd documenation

npm install

npm run dev
```

## Build
You may run this command to build the website. Make sure you are in the /docs directory

```bash
cd docs

npm run docs:build
```
